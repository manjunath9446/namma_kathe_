# 📖 Namma Kathe

**Namma Kathe** is an Android application developed using **Kotlin** and **Android Studio**, designed to provide an engaging platform for storytelling and cultural narratives through a modern mobile experience.

---

## 🚀 Features

- 📚 Story reading and viewing interface
- 🎨 Modern and responsive UI
- 📱 Native Android application
- 🔤 Custom font integration
- ⚡ Smooth navigation and optimized performance
- 🖼 Resource management using XML layouts and drawables
- 🎯 User-friendly experience

---

## 🛠 Tech Stack

### Mobile Development
- Kotlin
- XML
- Android SDK
- Android Studio

### Android Components
- Activities
- Fragments
- Layout Resources
- Drawables
- Material Design Components

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/manjunath9446/namma_kathe_.git
```

### Open Project

```bash
Open Android Studio
File → Open → Select Project Folder
```

### Run Application

```bash
Sync Gradle → Build Project → Run App
```
